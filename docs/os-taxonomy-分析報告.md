# os-taxonomy 專案分析報告（台灣版建置前置評估）

分析日期：2026-07-11 ｜ 分析對象：[withmarbleapp/os-taxonomy](https://github.com/withmarbleapp/os-taxonomy)（v1，2026-07-08 產出，1.7k stars / 302 forks）

## 一、專案是什麼

Marble（Generative Spark, Inc.）把自家產品內部的「小學階段學習知識圖譜」開源。它不是課綱的照抄，而是把多國課綱**蒸餾**成 1,590 個「微主題（micro-topic）」，每個微主題是一個可教、可驗收的最小知識單位，再用 3,221 條先修關係邊串成一張 DAG（有向無環圖）。實測驗證：圖確實無環（Kahn 拓撲排序 1,590/1,590 全數通過），100 個起點節點（無先修）、327 個終端節點。

## 二、資料架構（四個 JSON 檔 + Schema + 驗證器）

純資料、零執行期依賴。`data/` 四檔約 4MB，`schema/` 附 JSON Schema，`scripts/validate.mjs` 做結構、參照完整性、計數與 SHA-256 檢查。

### 1. topics.json（節點，1,590 筆）

每個微主題欄位：

| 欄位 | 說明 |
|---|---|
| `id` | 穩定識別碼 `mt_xxx` |
| `type` | CONCEPTUAL 810 / PROCEDURAL 512 / META 144 / LANGUAGE 75 / REPRESENTATIONAL 49 |
| `subject` / `domain` | 學科／領域（如 English / Grammar & Punctuation） |
| `name` / `description` | 白話名稱與描述 |
| `ageRangeStart/End` | 年齡帶（4~12 歲為主，最常見 7-9、9-11） |
| `centrality` | 中心性分數（最高者：一對一點數、加總概念、握筆坐姿——即「解鎖最多後續」的節點） |
| `evidence[]` | 精熟證據判準（可觀察行為） |
| `assessmentPrompt` | 給家長的自然語言檢核提示，含 `{{name}}` 占位符 |
| `standards[]` | 對應課綱條目 key（`課綱slug:代碼`） |

### 2. dependencies.json（邊，3,221 筆）

`{ topicId, prerequisiteId, strength: hard(2,025)/soft(1,196), reason }`——每條邊附一句先修理由。跨學科邊 161 條（如數學→自然），反轉邊即為「解鎖」關係。

### 3. curriculum-standards.json（來源課綱，7 套、3,261 條）

UK National Curriculum（全文，OGL v3）、CCSS ELA/Math（全文，CCSS 授權）、NGSS K-5/MS、C3 社會、IB PYP PSPE（後四套**只給代碼不給原文**，因上游授權不允許轉散布）。注意：1,590 個微主題中有 772 個**沒有**對應課綱條目——代表近半內容是 Marble 自行增補的（生活技能、學習如何學習等）。

### 4. clusters.json（183 筆）

以（學科 × 領域 × 年齡帶）為單位的家長友善摘要段落，給非專業使用者看的「你的孩子正在學什麼」。

### 學科分布

Science 547、Mathematics 503、English 286、History 90、PSD 88、Life Skills 37、Computing 21、Learning to Learn 18。

## 三、設計上值得學的地方

1. **微主題化而非照抄課綱**：課綱條目粒度不一，拆成單一可教概念後才能做個人化路徑推薦。
2. **DAG + 邊帶理由與強度**：hard/soft 區分「非會不可」與「有幫助」，`reason` 讓 AI 應用能向家長解釋「為什麼要先學這個」。
3. **evidence + assessmentPrompt**：每個節點自帶驗收標準，直接可餵給 LLM 做形成性評量。
4. **課綱對應層與內容層分離**：微主題是自有 IP，課綱只是對照表，授權風險隔離乾淨（codes-only 機制）。
5. **工程紀律**：manifest 校驗和、validate 腳本、CITATION.cff、PROVENANCE.md 交代每套課綱的授權，是可直接沿用的開源資料集範本。

## 四、授權（做台灣版前必懂）

三層授權：

- **資料庫結構**（集合、ID、關係）：ODbL 1.0——可商用，但**衍生資料庫必須以 ODbL 開源回饋**；在產品內使用（produced work）則不受限。
- **Marble 撰寫的文字**（description、evidence、reason 等）：CC BY-SA 4.0，同樣 share-alike。
- **課綱原文**：各自上游授權，Marble 無權轉授。

**關鍵推論**：若台灣版是「翻譯／改編這份資料庫」→ 屬衍生資料庫，必須 ODbL 開源＋署名。若「只借鏡 Schema 與方法論、內容從 108 課綱重建」→ 全新資料庫，授權自主（Schema 結構本身不受著作權保護）。

## 五、台灣版對應素材

台灣的對應原料是**十二年國教課綱（108 課綱）各領域領綱**的「學習重點」＝「學習內容」（如數學 `N-1-1`）＋「學習表現」（如 `n-I-1`），來源為國教院／教育部 CIRN 網站，以 PDF 為主，目前無官方機器可讀格式（JSON/API），需自行解析或人工結構化。國小階段涵蓋：國語文、英語文、數學、自然科學、社會、綜合活動、健體、藝術、科技（部分）＋本土語文。政府課綱文本的再利用通常適用政府資訊公開原則，實作前建議確認 CIRN 的資料開放宣告條款。

os-taxonomy 與 108 課綱的落差點（決定重建工作量）：

- **語文領域完全不可移植**：English 286 個微主題是英語母語者的 phonics／grammar 路徑，台灣需要的是「國語文」（注音、識字寫字、閱讀理解）＋「英語文（外語）」兩套全新圖譜。
- **數學高度可移植**：數學概念先修關係具普世性，503 個節點的圖結構可當骨架，對應到 108 課綱 N/S/R/A/D 主題軸。
- **自然科學大致可移植**：概念相通，但年段配置不同（台灣自然從國小三年級開始）。
- **社會／綜合活動需在地重建**：History 90 個節點是英美史觀；台灣社會領域（歷史、地理、公民）與綜合活動須從領綱長出來。
- **年齡帶 → 年段轉換**：ageRange 需改為台灣學習階段（第一學習階段＝1-2 年級、第二＝3-4、第三＝5-6）。

## 六、建置路線選項（QODA）

| 路線 | 做法 | 優點 | 缺點 | 授權後果 |
|---|---|---|---|---|
| A. 翻譯改編 | Fork 後翻成繁中、重對應 108 課綱 | 最快見效 | 語文／社會內容錯置，翻完仍要大改；品質債 | 衍生資料庫，強制 ODbL + CC BY-SA 開源 |
| B. 全新重建 ★ | 沿用 Schema／方法論，內容由 108 課綱學習重點以 AI 輔助拆解＋人工審校 | 完全貼合台灣課綱；授權自主；可自訂注音、本土語文等台灣特有領域 | 工作量最大（估 1,500~2,500 節點） | 全新資料庫，授權自選 |
| C. 混血 | 數學＋自然沿用其圖為骨架改寫，語文／社會／綜合全新建 | 省下最普世的 ~1,000 節點工 | 仍是衍生資料庫；兩種血統維護較繁 | 整體視為衍生，須 ODbL 開源 |

★ 推薦 **B**（若本來就打算開源回饋社群，C 是務實折衷——反正都要開源，先借數學／自然骨架能省一半力氣）。

## 七、建議的台灣版 Schema 調整

沿用四檔架構，欄位微調：`ageRange` → `stage`（學習階段）＋ `grade`；`standards` 對應 `108課綱:領域-代碼`（學習內容與學習表現分開連結）；`subject` 改為九大領域＋注音符號、本土語文；`assessmentPrompt` 與 `clusters.summary` 以台灣家長語境撰寫；新增 `sourceStandardText` 欄（政府文本可收錄全文，無 codes-only 問題，待確認開放條款）。
