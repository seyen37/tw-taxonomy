## 1年級・數與量

### 唱數到一百（PROCEDURAL｜中心性1.0）

能依正確順序從1唱數到100，並能從中間任一個數接著往下數。這是認識數的第一步，也是點數的基礎。

- 精熟證據：能從1依序唱數到100不跳號；能從指定的數（如37）接著往下數
- 家長檢核：請{{name}}從1數到100，再試試「從58開始數到65」，看看能不能不從頭數。
- 課綱對應：N-1-1｜n-I-1

### 一對一點數（CONCEPTUAL｜中心性0.9935）

點數物品時，一個物品配一個數詞，不重複也不遺漏，並知道最後說出的數就是總共的個數。

- 精熟證據：點數20個以內的物品，每個物品只點一次；點完能說出「總共有幾個」
- 家長檢核：給{{name}}一把彈珠（15顆以內），請他數數看有幾顆。觀察他是否一顆一顆點、最後能說出總數。
- 課綱對應：N-1-1｜n-I-1
- 先修：唱數到一百（hard：要點數必須先會依序唸出數詞）

能報讀、說明並製作圓形圖（含百分率圓形圖），理解圓形圖呈現「部分佔整體」的比例。

- 精熟證據：能從圓形圖讀出各類佔比；能把百分率資料畫成圓形圖
- 家長檢核：給{{name}}看零用錢支出圓形圖，問「花最多的是哪類？佔多少？」
- 課綱對應：D-6-1｜d-III-1
- 先修：長條圖與折線圖的報讀（hard：統計圖體系的擴充）；比率與百分率（hard：圓形圖以百分率分配）；扇形與圓心角（soft：圓形圖的分區是扇形）

### 可能性的初步認識（CONCEPTUAL｜中心性0.0）

能從統計圖表資料回答可能性問題，用「很有可能」「很不可能」「A比B可能」描述不確定事件（機率前置經驗）。

- 精熟證據：能依資料判斷哪個結果比較可能；能用可能性語言描述生活事件
- 家長檢核：問{{name}}：「袋子裡8顆紅球2顆白球，抽到哪色比較可能？為什麼？」
- 課綱對應：D-6-2｜d-III-2
- 先修：圓形圖（soft：從統計圖表資料出發）；比率與百分率（soft：可能性大小的比較近似比率直觀）

## 6年級・關係

### 數的計算規律整合（CONCEPTUAL｜中心性0.0）

認識整數、小數、分數都是數，享有相同的四則計算規律（交換律、結合律、分配律），並知道乘除的規律可用於簡化計算。

- 精熟證據：能說出分數也適用分配律；能用規律簡化混合計算
- 家長檢核：問{{name}}：「0.5×7＋0.5×3有沒有快的算法？分數也可以這樣嗎？」
- 課綱對應：R-6-1｜r-III-1、r-III-2
- 先修：分配律與計算簡化（hard：規律體系的總整理）；分數的除法（soft：確認分數也適用相同規律）

### 數量關係的觀察與推理（CONCEPTUAL｜中心性0.0131）

能從具體情境或數量模式觀察規律，進行推理並說明（代數與函數的前置經驗）。

- 精熟證據：能發現「輸入輸出」表的規則；能說明自己推理的依據
- 家長檢核：給{{name}}一個對應表（1→3、2→5、3→7），問「10會變成多少？規則是什麼？」
- 課綱對應：R-6-2｜r-III-3
- 先修：二維數量模式與奇偶數（hard：模式推理的深化）

### 數量關係的文字與符號表示（LANGUAGE｜中心性0.0）

能把情境中的數量關係用文字或符號列成關係式（如「總價＝單價×數量」寫成y＝a×x的雛形）。

- 精熟證據：能把規律寫成含符號的式子；能解釋式子中每個符號的意義
- 家長檢核：請{{name}}把「每枝筆15元，買x枝要多少錢」寫成式子。
- 課綱對應：R-6-3｜r-III-3
- 先修：以符號表示數學公式（hard：符號表示經驗的延伸）；數量關係的觀察與推理（hard：先觀察出關係才能表示）
